# Security Policy

Deep Cuts is a local-first portfolio app (ADR-0013). Security controls are described in [ADR-0008](docs/adr/0008-security-baseline.md) and the [threat model](docs/security/threat-model.md).

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** ("Report a vulnerability" under the Security tab). Do not open a public issue. Expect an acknowledgement within 7 days.

## Supported versions

Only the latest `main` is supported.
